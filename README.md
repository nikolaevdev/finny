# Питомец Финни

Прототип Android-приложения для формирования базовых финансовых навыков у детей 7–11 лет через виртуального питомца.

## Текущий статус: Этап 3

Этап 3 строится поверх исправленного Этапа 2 и добавляет первое настоящее игровое состояние.

Реализовано:

- локальный профиль без регистрации и обязательных персональных данных;
- создание Финни и 27 комбинаций внешности;
- восстановление профиля после перезапуска;
- локальное сохранение игрового состояния через `shared_preferences`;
- одна игровая валюта – монеты;
- текущий баланс;
- фактические накопления на выбранную цель;
- выбранная цель `Уголок исследователя`;
- в доменной модели заранее предусмотрены 3 финансовые цели;
- игровой период `1 из 5`;
- явное начало периода и источник виртуального дохода;
- начисление 120 игровых монет только один раз при старте периода;
- экран планирования бюджета по направлениям `Нужно / Хочу / Коплю`;
- ограничение: нельзя распределить больше доступного баланса;
- можно оставить часть монет свободной;
- подтверждение плана и его сохранение после перезапуска;
- главный экран показывает реальный баланс, цель и статус периода.

## Проверка Этапа 3

1. Выполнить `flutter pub get`.
2. Запустить приложение командой `flutter run`.
3. Создать локальный профиль и Финни или открыть сохранённый профиль Этапа 2.
4. На главном экране открыть `План`.
5. Нажать `Получить 120 монет и начать`.
6. Проверить, что источник дохода явно показан как `Карманные монеты на период`.
7. Распределить монеты между `Нужно`, `Хочу`, `Коплю` кнопками `−10/+10`.
8. Попробовать распределить больше 120 монет – приложение не должно позволить это сделать.
9. Подтвердить план.
10. Полностью закрыть приложение и запустить снова.
11. Проверить, что баланс, накопления, номер периода и подтверждённый бюджет восстановились.

## Демо-профиль

Для демо-профиля цель `Уголок исследователя` начинает со 120 накопленных монет из 180. Это позволяет позднее быстро показать механику достижения цели без ожидания нескольких игровых периодов.

В обычном профиле накопления начинаются с 0.

## Архитектура Этапа 3

```text
lib/
├── app/
├── core/
└── features/
    ├── onboarding/
    ├── profile/
    ├── pet/
    ├── home/
    ├── game/
    │   ├── application/
    │   ├── data/
    │   └── domain/
    └── budget/
        └── presentation/
```

`GameState` отделён от `PlayerProfile`: профиль отвечает за игрока и внешний вид питомца, игровое состояние – за баланс, накопления, период и бюджет.

## Важно про дизайн

Текущий UI остаётся функциональным каркасом. Финальный визуальный слой будет реализован позднее прямо во Flutter по утверждённым референсам: уютная база исследователя, Финни, походный рюкзак бюджета, игровой магазин и визуальное развитие цели.

## Windows

В `android/gradle.properties` временно оставлено:

```properties
kotlin.incremental=false
```

Это обход ошибки Kotlin incremental cache, когда проект находится на `F:`, а стандартный Pub Cache – на `C:`.

Файлы `.idea`, `.dart_tool`, `build`, `android/.gradle`, `android/.kotlin`, `*.iml` не следует переносить между архивами проекта.
