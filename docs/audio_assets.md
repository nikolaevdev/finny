# Звуки и музыка Финни

В проект включены четыре коротких звуковых сигнала и три фоновых трека. Аудио работает нативно на Android через `SoundPool` и `MediaPlayer`; сетевой доступ и отдельный Flutter-пакет не нужны.

## Фоновая музыка

Исходные файлы распределены так:

| Исходный файл | Ресурс в приложении | Назначение |
|---|---|---|
| `bouncing-adventure.mp3` | `finni_music_01_shop.ogg` | Магазин, награды, итог периода |
| `magical-quiet.mp3` | `finni_music_02_calm.ogg` | Спокойные игровые и служебные разделы |
| `bouncing-motif.mp3` | `finni_music_03_main.ogg` | Основная тема Finny |

| Ресурс | Назначение | Уровень в проигрывателе |
|---|---|---:|
| `finni_music_01_shop.ogg` | Магазин, награды, итог периода | 0.16 |
| `finni_music_02_calm.ogg` | Бюджет, задания, накопления, прогресс, настройки, взрослый раздел | 0.12 |
| `finni_music_03_main.ogg` | Главный экран, онбординг, профиль, создание Финни | 0.15 |

Исходные MP3 оптимизированы для мобильной сборки:

- формат – OGG Vorbis;
- частота – 48 кГц, stereo;
- средняя громкость – около `-18 LUFS`;
- лишние паузы в начале и конце удалены;
- для перехода через конец файла используется циклический crossfade 0,8 с;
- каждый трек повторяется через `MediaPlayer.isLooping = true`.

После перекодирования три файла занимают около 6,3 МБ вместо 11,6 МБ исходных MP3.

Музыкальная сцена выбирается по маршруту приложения. При переходе в другой раздел Android-проигрыватель переключает ресурс, а при возврате восстанавливает музыку соответствующего экрана. Переключатель `Фоновая музыка` действует на все три трека. При сворачивании приложения проигрыватель освобождает аудиофокус.

## Звуковые сигналы

| Файл | Где используется | Формат |
|---|---|---|
| `finni_tap.wav` | Нажатия кнопок, карточек и плиток | PCM 16-bit, mono, 22 050 Гц |
| `finni_success.wav` | Подтверждение бюджета, накоплений, задания и завершение периода | PCM 16-bit, mono, 22 050 Гц |
| `finni_warning.wav` | Ошибка в задании или нехватка монет | PCM 16-bit, mono, 22 050 Гц |
| `finni_purchase.wav` | Успешная покупка | PCM 16-bit, mono, 22 050 Гц |

Скрипт `python3 tools/generate_audio.py` пересоздаёт только четыре WAV-сигнала и не меняет фоновые треки.

Если музыку потребуется заменить, сохраните текущие имена ресурсов. Тогда маршрутизация по сценам останется без изменений.
