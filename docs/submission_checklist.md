## 4. Краткое описание для формы подачи

> «Питомец Финни» — локальное Android-приложение для детей 7–11 лет, обучающее планированию бюджета, осознанным покупкам и накоплениям через заботу о виртуальном персонаже. За пять игровых периодов ребёнок распределяет доход по категориям «Нужно / Хочу / Коплю», решает финансовые задания, собирает средства на цели и получает понятную обратную связь. Настроение и развитие Финни отражают игровые решения. Прототип не требует регистрации и не использует реальные деньги.
