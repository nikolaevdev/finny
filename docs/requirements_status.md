# Статус обязательных требований

Актуально для Этапа 10.

| Раздел ТЗ | Требование | Статус | Текущее состояние |
|---|---|---|---|
| 2.5.1 | Первый запуск и локальный профиль | В работе | Есть онбординг и локальный профиль без регистрации. Возврат к подсказке из приложения будет добавлен вместе с настройками. |
| 2.5.2 | Создание виртуального питомца | Реализовано | Настройка внешности и игрового имени питомца. |
| 2.5.3 | Главный экран | В работе | Питомец, баланс, накопления, активная цель, показатели состояния и стадия развития отображаются. Доступны план, магазин, накопления, задания, итог периода, учебный прогресс и раздел для взрослого. Настройки будут реализованы отдельным этапом. |
| 2.5.4 | Игровая валюта и получение дохода | Реализовано | Используется одна игровая валюта. При старте каждого периода показываются источник и сумма начисления. |
| 2.5.5 | Планирование бюджета | Реализовано | Есть план `Нужно / Хочу / Коплю`, контроль суммы, подтверждение и сравнение плана с фактическими расходами и накоплениями при завершении периода. |
| 2.5.6 | Покупки и расходы | Реализовано | 8 товаров двух типов, цена, категория, влияние, подтверждение, списание, история текущего периода и обработка нехватки средств. После завершения периода новые покупки блокируются. |
| 2.5.7 | Накопления и финансовая цель | Реализовано | Доступны 3 цели, выбор активной цели, стоимость, накопленная сумма, остаток и прогресс. Можно переводить монеты в накопления. Снятие выполняется только после отдельного подтверждения. После обычного завершённого периода переводы блокируются до перехода к следующему; после пятого периода остаток баланса можно продолжать переводить в накопления и обратно без изменения истории завершённого периода. |
| 2.5.8 | Игровые задания | Реализовано | Есть 6 заданий по 3 темам. После успешного и ошибочного решения показывается короткое объяснение. Все задания доступны сразу, включая демонстрационный режим. |
| 2.5.9 | Обратная связь и безопасная ошибка | Реализовано | После финансовых действий показываются последствия. Покупки меняют связанные показатели Финни, а итог периода объясняет причину изменения настроения и предлагает понятный следующий шаг без негативной оценки ребёнка. |
| 2.5.10 | Прогресс и развитие питомца | Реализовано | Есть 4 обратимых состояния настроения и 3 стадии развития. Рост рассчитывается по нескольким завершённым периодам с учётом обязательных расходов, соответствия плану и регулярности накоплений. |
| 2.5.11 | История и учебный прогресс | Реализовано | Есть отдельный раздел прогресса: завершённые задания по трём темам, прогресс текущей финансовой цели, итог последнего периода, история завершённых периодов и короткий словарик основных финансовых терминов. |
| 2.5.12 | Раздел для взрослого | Реализовано | Раздел отделён арифметическим барьером. Показываются цели приложения, пройденные темы, общий прогресс, прогресс периодов и цели без негативных оценок ребёнка. Для демо-профиля доступен подтверждаемый сброс игрового прогресса. |
| 2.5.13 | Сохранение состояния и демонстрационный режим | Реализовано | Профиль, баланс, покупки, накопления, выбранная цель, учебный прогресс и итоги периодов сохраняются. 5 периодов проходят подряд без календарного ожидания. У демо-профиля есть подтверждаемый сброс к исходному игровому состоянию для повторной экспертной проверки. |
| 2.5.14 | Управление контентом | В работе | Контент магазина и финансовых заданий отделён от UI. Новое задание можно добавить в каталог без изменения основной игровой логики. |

## Минимальный демонстрационный контент

| Элемент | Требование ТЗ | Этап 10 |
|---|---:|---:|
| Визуально различимые комбинации питомца | не менее 9 | 27 базовых комбинаций внешности + визуальные индикаторы настроения и стадии роста |
| Последовательные игровые периоды | не менее 5 | 5, переходы и завершение реализованы без ожидания реального времени |
| Задания | не менее 6 по 3 темам | 6 по 3 темам, есть успешные и ошибочные варианты |
| Покупки | не менее 8 двух типов | 8 |
| Цели накопления | не менее 3 целей | 3, выбор, пополнение и прогресс реализованы |
| Стадии развития питомца | не менее 3 | 3 (`Малыш`, `Подрос`, `Уверенный Финни`) |

## Исправление после Этапа 9

После завершения пятого периода оставшийся баланс больше не блокируется без возможности использования. Пользователь может перевести остаток в накопления или снять средства из накоплений обратно на баланс. Эти операции выполняются уже вне завершённого периода и не изменяют сохранённый `план / факт` пятого периода.

## Совместимость сохранений

Этап 10 не меняет формат сохранения: используется `GameState.schemaVersion = 4`. Раздел для взрослого строится по уже сохраняемым данным, а сброс демо-профиля создаёт штатное исходное `GameState.initial(demoMode: true)`. Сохранения Этапа 9 и схем 1–3 продолжают загружаться прежней миграционной логикой.
